# Changelog

## 1.0.0 — 2026-10-10

- Yandex SmartCaptcha advanced invisible widget for standard WordPress comments/auth forms.
- Visible checkbox widget after repeated submissions or risk signals.
- Server-side one-time token validation, host verification, honeypot.
- AES-256-GCM encrypted server key, separate form switches and configurable attempt window.
- Last 30 anonymized events and 7-day counters in admin.
- PHP integration API for nonstandard forms.
